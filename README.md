# Super Mario Bros

## Overview
This project is developed as part of the Object-Oriented Programming course at HCMUS (Ho Chi Minh City University of Science). This project demonstrates OOP principles through game development using C++ and raylib.

## Course Information
- **Course**: Object-Oriented Programming
- **Program**: Advanced Program in Computer Science (APCS)
- **University**: Ho Chi Minh City University of Science (HCMUS)
