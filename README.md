# Super Mario Bros

## Overview
This project is developed as part of the Object-Oriented Programming course at HCMUS (Ho Chi Minh City University of Science). This project demonstrates OOP principles through game development using C++ and raylib.

## Course Information
- **Course**: Object-Oriented Programming
- **Program**: Advanced Program in Computer Science (APCS)
- **University**: Ho Chi Minh City University of Science (HCMUS)

### Features Demonstrated
- Multiple character selection (Mario/Luigi)
- Multiple Player
- Three difficulty levels
- Power-ups system
- Enemy AI
- Smooth camera movement
- Particle effects
- Score system

## Set up
- Language: C++
- Library: raylib
- External: tmxlite, ECS

## 🛠️ How to Get Started?
**Clone the Repository**:
   ```bash
   git clone https://github.com/hannguyen2880/cpp-super-mario.git
   mkdir build
   cd build
   cmake ..
   make
   ./super-mario
   ```
